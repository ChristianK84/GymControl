¿Qué es GymControl?

GymControl es un sistema de gestión diseñado para el control integral de un gimnasio. Permite administrar alumnos, maestros, asistencias, membresías y la comunicación con los tutores de manera ágil y centralizada.

Funcionalidades principales

Módulo Descripción
Alumnos Registro de alumnos con ficha médica, datos del tutor y código QR de asistencia.
Maestros Gestión de entrenadores y asignación de alumnos.
Asistencias Control de asistencia mediante escaneo de código QR o registro manual.
Membresías Planes de membresía, pagos, recibos por correo y control de días extra.
